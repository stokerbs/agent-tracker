# Owner playbook — งานฝั่งเจ้าของที่เตรียมให้ลงมือได้ทันที

เอกสารนี้รวบรวมงานในแผน (Part 13) ที่ต้องทำโดยเจ้าของหรือ Agency ไม่ใช่โค้ด พร้อมข้อความและสเปกที่พร้อมใช้ ทุกข้อความใช้เฉพาะข้อเท็จจริงที่ยืนยันแล้วใน `src/lib/marketing/facts.ts` และ `contact.ts` (ตั้งแต่ปี 2016 · ปิดเคส 1,953+ · 77 จังหวัด · Fastwork 4.8/5 จาก 63 รีวิว · มัดจำ 50%) ห้ามเติมตัวเลขอื่นจนกว่าจะยืนยันในแบบฟอร์ม `facts-to-confirm.md`

ลำดับที่แนะนำ: **1 → 2 → 3** ภายในสัปดาห์แรก (ปลดล็อกการวัดผลและ Local SEO) จากนั้น **4** ต่อเนื่อง 3 สัปดาห์ และ **5–7** เมื่อมี case study อย่างน้อย 3 เคส

## 3. GTM / GA4 / Google Ads — ตั้ง conversion (ข้อ C3)

เว็บส่ง event ผ่าน dataLayer อยู่แล้ว (`src/lib/marketing/analytics.ts`) ให้ Agency สร้าง GA4 event และตั้งเป็น conversion ตามนี้:

| Event ที่เว็บส่ง | พารามิเตอร์ | ตั้งเป็น GA4 conversion? | นำเข้า Google Ads |
|---|---|---|---|
| `lead_submitted` | case_type, locale, lead_ref, page | ใช่ (หลัก) | ใช่ — "Lead form" (Secondary หลังเริ่ม offline conversions) |
| `assistant_lead_created` | page, lang | ใช่ | ใช่ — "Lead form" (รวมกับด้านบน) |
| `contact_click` | channel (line / whatsapp / phone / email / facebook), placement, page, lang | ใช่ เฉพาะ channel = line, whatsapp, phone | ใช่ — "Contact click" (Secondary / observation) |
| `zh_intake_submitted` | service, country, budget_range, urgency, lead_ref | ใช่ | ใช่ — "Lead form (zh)" |
| `partner_intake_submitted` | partner_type, country | ใช่ | ไม่ (B2B) |
| `assistant_opened`, `wechat_cta_click`, `zh_intake_start` | — | ไม่ (engagement) | ไม่ |

หลังรัน migration 0128 และสร้าง conversion action ชื่อ **Qualified lead** และ **Paid case** (ข้อ C8) ให้ตั้งสองตัวนี้เป็น **Primary** สำหรับ bidding และลด "Lead form" เป็น Secondary เมื่อมีการอัปโหลด offline conversions ต่อเนื่อง ≥ 4 สัปดาห์ รายละเอียดใน `ads-offline-conversions.md`
